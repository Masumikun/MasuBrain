# Aula 4
**Método da Instância** e **método da classe** sendo diferente, sendo **sintaxe** de **instância** segue pelo **func** enquanto de **classe** possui uso de **static**.

**encapsulamento** serve para projetos grandes atribuindo os **componentes** que são criados.

## Estrutura & Tipagem De Dados
```gdscript
# Tipos basicos com tipagem explicita
var inteiro : int = 16
var decimal : float = 3.64
var texto : String = "ola, mundo!"
var booleano : bool = true
var vectoe2d : Vector2 = Vector2(100, 200)
var vector3d : Vector3 = Vector3(1, 2, 3)
var cor : Color = Color(1, 0, 0)
var dicionario : Dictionary = {"chave", "valor"}
var lista : Array = [1, 2, 3]
var nulo : Variant = null

# Tipagem inferida com o operador := 
var idade := 25
var saldo := 99.99
var nome := "Luna"
var ativo := false
var posicao := Vector(50, 75)
var inventario := ["espada", "escudo"]
var dados := {"forca": 12}
```
