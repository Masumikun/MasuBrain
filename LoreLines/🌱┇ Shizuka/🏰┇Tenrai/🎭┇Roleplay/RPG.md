# Aprendizado
Quando haver uma **interpretação** seja menos complexas, simplesmente são fáceis de serem feitos para **jogador**, não seja nescessário uso de **teste**, deve apenas passar como **encenação**.

## Testes
**Interpretação** tem ***dinâmica*** de fortalecer ampla questão sobre realmente ter uma lógica escolhida pelo jogador ou por mim.

se caso envolver uma situação de teste que tenha dado **empate** deve da **reroll** ou alguém ter maior **resultado**, porém o caso pedido de **ação** seja um teste de envolver apenas **dificuldade** vai ser com **resultado** sendo *maior ou igual* da *dif*. Mas, se **jogador** precisar algo como desafio ele vai fazer teste puro sendo o **teste de destino**

## Ações
uso de **ação** como algo único por turno do **jogador**, sendo que podem usar 5 **ações** disponíveis.

## Combate
### Rodadas & Turnos
**Rodadas**➣ Sendo conjunto de turnos quando acontece rodada dentro dela se passaram **6s** por cada **cena** de jogo

**Turnos**➣ Sendo conjunto de ações que são apenas 5 opções disponíveis de ações sobre o jogo.

Durante esse processos acontece a **iniciativa**, sobre os **Alvos** de jogo.

#### Iniciativa
Sendo o processo de combate entre **alvos** que são gerenciados por **maior** número até **menor** número até.

`1d12 + agi` => **alvo inimigo**

skills seja elas de **caminho** ou **características**, poderão se usadas deste que sejam tipo **iniciativa**

### Emboscada
**alvos**(Emboscadores) que fazem emboscada sobre os **alvos inimigos** devem realizar teste de **Furtividade** vs **Percepção Passiva** quem tira maior número ganha **+6** de **agi** na **iniciativa** de **combate**.

**Emboscadores** que consegui fazer seus devidos teste, deixam os **alvos inimigos** em turnos depois do seu, mas caso não consigam não ganham o pontos

### Movimentação
- 6 metros base para todos
- +1 a cada 2pts de **agi**
